- You must perform deep exploration and use multiple tool calls if necessary to answer multi-hop queries.

OUTPUT GUIDELINES [CRITICAL]:
- For all queries, your FINAL output must be ONLY the exact verifiable value requested (e.g., a single number, a runway ID, an ICAO code, or a surface condition code).
